## 라운드별 델타·적대 판정

**R1 초안**: arc를 "셀 단위 arcMask"로 정의.
- 적대 반박 → **기각**: 리플렛 arc는 셀 경계를 넘는다(원슬 아치4 반원 = 문짝 전면, Image#2 6번 라운드탑 = 상단 2코너 관통). 셀 좌표계로는 커버리지가 안 나온다.
- 생존결함: ①arc 좌표계 부적합 ②아치 leaf가 통째로 아치형(실물은 직사각 문짝+아치 개구) ③패널별 패턴의 URL v1 파괴 ④비대칭 폭(2S 비대칭 1000~1300 실존 제품) 미표현 ⑤ABS 팔각/사각/원형 양개 유리는 arc로 불가.

**R2**: arc를 **문짝 정규화 좌표 + 앵커(코너/변) 기반**으로 재정의: `arcs: [{anchor: tl|tr|bl|br|left|right|top|bottom, rx, ry, fill: solid|glass}]`. 패턴 카드에 `spandrel: solid|glass` 추가(직사각 문짝 + 아치 유리 + 코너 처리). ShareState `v:2` + v1 디코드 호환(단일 patternId→균일 배열). 제품 카드에 `panelWidthFr`·`fixedPanels` 추가.
- 적대 반박 통과: 앵커+반경 2자유도로 Image#2 전 실루엣 도형 대조 완료(아래 커버리지 워크스루).
- 생존결함: ①2S 양개의 미러링(왼짝·오른짝 대칭) 표현 ②arc solid 오버레이와 셀 유리의 z-파이팅 ③제품별 패턴 적용가능성 필터(스윙 전용 조합이 3연동 목록에 뜸).

**R3**: 2S 두 번째 문짝 **자동 미러 기본**(비대칭 이스케이프 `mirror:false`). 렌더 전략 변경 — 셀별 box 대신 유리 1판 + solid 영역(사각+arc) 오버레이 z+2mm(ponytail: 근사, 실물은 동일면 랩핑). 패턴 카드 `motions?: string[]` 태그로 제품 필터.
- 적대 반박 통과: 오버레이 방식은 기존 arch ExtrudeGeometry 경로와 동일 기법 — 검증된 코드 재사용.
- 폐기이력 대조: R1-07(그리드+셀 재질) **확장이며 모순 아님** · R1-15 경계(견적·로그인 제외) 침범 없음 · R2-04 아치 근사 unconfirmed 규율 유지.
- 생존결함: ①ABS 팔각/사각/원형 유리형상 — arc 문법 밖.

**R4**: ABS 양개 유리형상은 **v2 비채택**(사유: R2-05가 ABS를 실루엣 근사로 이미 격리, 팔각은 octagon 별도 프리미티브 필요 — 수요 확인 전 YAGNI). 문서에 한계·업그레이드 경로 기록으로 종결. 새 생존결함 0.

**R5**: 무수확 2연속 + 점수 정체 → **수렴 선언**.

## 수렴 플랜 (v2 스펙)
1. **PatternGrid v2** (`types.ts`·Zod·build-cards): `arcs?: {anchor, rx, ry, fill}[]` (문짝 정규화 좌표) · `spandrel?: 'solid'|'glass'` · `motions?: string[]`. 기존 카드 전부 무수정 유효(전 필드 optional).
2. **PanelMesh v2**: 유리 1판 + solid 오버레이(사각 셀 + arc Extrude) + spandrel 아치(직사각 문짝 유지). 기존 archProfile 경로는 spandrel 없을 때 유지(하위호환).
3. **패널별 패턴**: `panelPatterns?: PatternId[]` (ShareState v:2, v1 링크 호환 디코드) · 제품 카드 `panelWidthFr?`·`fixedPanels?` · 2S 자동 미러.
4. **ㄱ자 수정**: 측면 패널 슬라이드 제거 → 고정 픽스(손잡이 없음, fixedPanels로 표현). 근거: 주인님 실물 확인 — 정면만 개폐, 측면은 창+돌출 구조. 수렴 결정 8 전제 갱신.
5. **프리셋 등록**: 킬-실험 3종 통과 후 대표 ~15종 카드 등록(원슬 아치 6 + 스윙 대표 + 3연동 잔여), 나머지는 R1-08 등록 절차로 점진.

## 크럭스 (불가역 1)
**arc 좌표계 = 문짝 정규화 + 앵커 방식.** 프리셋 카드가 이 좌표계로 쌓이기 시작하면 이후 변경 비용이 카드 수에 비례해 커진다.

## 킬-실험 (가장 싼 게이트)
최난도 3종을 카드로 먼저 등록 → 실렌더 → 리플렛 사진 크롭과 나란히 비교:
① 원슬 아치4(문짝 전면 반원 solid) ② Image#2 R1-6(라운드탑 2코너 arc) ③ Image#2 R3(도어+픽스 사이드라이트 조합).
PASS = 실루엣 일치. FAIL = 좌표계 문법이 틀린 것 — 대량 등록 전에 문법을 고친다.

## 구현 추기 (문법 세부 — 루브릭 불변)
- **`invert` 플래그 추가**: 라운드탑 코너는 사분타원 디스크가 아니라 그 **보수 영역**(코너 사각 − 디스크) — 수렴 시점에 놓친 세부. anchor 코너에서만 유효.
- 홀(hole)이 외곽선과 접촉하는 Shape는 earcut 삼각분할이 깨짐 → 스팬드럴 웨지 2개·환형 밴드를 홀 없는 폐곡선으로 구성.
- 등록 완료 프리셋 10종 + 제품 2종(swing-sidelite, swing-2s). 잔여 ~30종은 R1-08 등록 절차로 점진 (사진 크롭 대조 필수, geometrySource: approx).
