# WIREFRAMES — 문다온 3D 쇼룸 (UI/UX 정본)

톤: 라이트 미니멀 + 우드·샴페인골드 악센트. 소재가 주인공, UI는 물러남.

## W1 · 데스크톱 메인 (컨피규레이터)
```
┌────────────────────────────────────────────────────────────────┐
│ 문다온            [제품선택▾]        [AR로 보기] [공유] [캡처]  │
├───────────────────────────────────────────┬────────────────────┤
│                                           │ ◆ 커스텀            │
│                                           │ ┌─ 색상 ─────────┐ │
│            3D 뷰포트 (현관 목업)           │ │ ●●●●● +랩핑시트 │ │
│         [문: 초슬림 3연동 1.9]            │ ├─ 유리 ─────────┤ │
│                                           │ │ ▢투명 ▢브론즈…  │ │
│                                           │ ├─ 디자인 ───────┤ │
│                                           │ │ 오픈형|고시형|디바│ │
│                                           │ ├─ 손잡이 ───────┤ │
│                                           │ ├─ 치수 ─────────┤ │
│                                           │ │ 가로 ────●── B구간│ │
│   닫힘 ●─────────────○ 열림   [▶ 자동재생] │ └────────────────┘ │
├───────────────────────────────────────────┴────────────────────┤
│ 품질: 고급유리 ◉  간단 ○          제작사례와 비교 →            │
└────────────────────────────────────────────────────────────────┘
```
- 개폐 슬라이더 = motion 파라미터 t 직결 (드래그로 문을 밀어보는 감각)
- 우측 패널 아코디언 5축. 선택 즉시 3D 반영
