# SCENE-PLAN — 씬(Entryway) 사실감 로드맵

2026-08-26 조준 판정 기준: 재질 절반·빛 절반·현관 미착수 (완결 경로 0/3). 원칙 — **문이 주인공**, 배경은 "살고 있는 집"의 힌트만. 소품 제작 절차는 `.claude/skills/소품/SKILL.md`.

## 개선 축 (순서대로)

1. **재질** — 단색 면을 질감으로. 벽 미세 요철, 강마루 나뭇결 반사, 현관 포세린 타일. 소스: ambientCG(CC0). 모델 추가 없이 최대 효과.
2. **빛** — ACES 톤매핑 확인, 접지그림자(ContactShadows), 다운라이트·코브 색온도 2700K대 통일. 유리 너머 현관 센서등 은은한 빛(유리 재질감 동반 상승).
3. **현관(유리 너머)** — 항상 프레임 안. 빈 무대 → 생활 공간.
4. **거실 소품** — 카메라 앞. 국룰 배치만 최소로.
