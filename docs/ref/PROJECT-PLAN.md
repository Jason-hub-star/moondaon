# PROJECT-PLAN — 페이즈 P1~P6

각 페이즈 게이트: ①해당 모델 개폐+커스텀 실렌더 확인(스크린샷) ②카드 Zod 검증 통과 ③문서 동기화(STATUS·DECISION-LOG) ④커밋.

**전역 규약(수렴 반영)**: 1 unit = 1m · 카드 id 불변 · URL 상태 `v` 필드 · AR은 정적 내보내기("실물 크기로 보기")

## P1a — 3연동 뼈대 (하드코딩 데이터)
- 3연동 파라메트릭 모델(문틀 117mm·문짝 19X32·패널 3) + 순차 겹침 개폐 + 현관 목업 씬
- **게이트 = 킬-실험 1**: 리플렛 실사진과 같은 앵글 나란히 스크린샷 → 주인님 실물감 판정. FAIL 시 P2 금지, 재질 재수렴
## P1b — 카드 파이프라인 + 5축 커스텀
- 카드 파이프라인: `data/cards/*.md`(제품·색상·유리·패턴·손잡이) → `scripts/build-cards.mjs`(Zod) → `apps/web/src/generated/`
- 색상 재판독: HEIC 견본 크롭 → hex 근사(`approx`)/`unconfirmed`
- 커스텀 5축 UI + URL 해시 공유(base64url+v)
- 완료판정: 브라우저에서 선택→커스텀→개폐 1회 통과
