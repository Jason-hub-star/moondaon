# Folder Guide

This folder holds session-level working notes.

- Keep file names stable: `YYYY-MM-DD-<work-unit>.md`.
- Do not duplicate long current status; link back to `docs/status/*`.
- Store detailed evidence here; copy only the one-line current truth back to `PROJECT-STATUS.md`.
- Sync checklist outcomes with `docs/status/WORK-BOARD.md` when Ops Extension is enabled.
